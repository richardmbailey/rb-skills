## Checks fixed before candidate inspection

- R1: An exactly representable trajectory starts with 8 kg and 3 kg, uses rate 0.5/day, two 0.5-day steps and a final 0.25-day step. Hand calculation gives A values 8, 6, 4.5, 3.9375 and B values 3, 5, 6.5, 7.0625. It detects receiving-store order mistakes and wrong final intervals. Sample immutability is checked.
- R2: Three bounded trajectories cover ordinary transfer, initially empty A, and the positivity boundary. They check nonnegativity, monotonicity, strictly increasing times and conservation with the specified mass-scaled roundoff allowance.
- R3: Integrating A'=-kA gives the independent exponential endpoint. B follows from conservation. The three prescribed step sizes test positive Euler bias in A depletion, the 3 kg endpoint bound and convergence ratios [1.9, 2.1]. B starts at 7 kg to avoid concealing an omitted receiving-store initial value.
- R4: Every argument is checked against all three non-finite categories and a negative value. Separate cases cover zero dt, unstable transfer, overflowing total mass, excessive step count and overflowing duration/dt. Valid limits include zero duration/rate, rate*dt=1, exactly 100000 steps and a decimal endpoint. A finite large-mass trajectory checks that intermediate arithmetic does not overflow when the mathematical transfer remains finite.
- R5: A fresh subprocess writes and reloads the exact small trajectory, checks all CSV columns and kg-to-tonnes values. Separate subprocesses check invalid-input rejection before output creation and a directory output error.
- R6/R7: Independent numerical and integration tests contribute to these requirements. The parent owns Hypothesis, development-tool and mutant evidence; this review will not substitute source inspection for those checks.

The reference values were not generated by candidate output. No random generator is used in these independent tests. The endpoint comparison's 1e-9 kg absolute allowance addresses roundoff when comparing two representations of the same error; it does not replace the required 3 kg discretisation bound or convergence interval.
