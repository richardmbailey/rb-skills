to the skill, especially reducing supporting code, followed by independent review.

The active instruction edition now defaults to a project workflow using existing
commands, native reports, a reusable evidence-note template and static HTML. It
does not require a custom scheduler, schema converter, general host adapter or
interactive report application merely to assess a small project. The assurance
workflow and its unchanged schemas remain binding when requested, already adopted
or required by a new enforced evidence/acceptance boundary.

coverage, actual execution identity, static scope, raw failures and final-candidate
comparison. All 43 capability headings and identifiers are unchanged. The numerical
example, prototype and original trial records were not modified or reclassified.

## Limits

No new project trial or matched old/new/without-skill experiment was run in this
instruction-only revision. Reduced infrastructure is an explicit procedural
change; actual code savings, speed improvements and future adherence are unmeasured.
The historical numerical trial remains insufficient under its original full gate.
No target example tests or unrelated constrained-runtime tests were rerun because
their implementation and policy artifacts did not change. No runner was built,
no schema semantics changed, and no commit or push was performed.
