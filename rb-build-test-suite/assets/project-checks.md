# Project checks

Use this as a starting structure in existing project documentation. Replace the
guidance with observed facts, omit irrelevant optional detail, and link raw outputs.
Do not mark a section complete merely because it contains a command or a plan.

## Scope and acceptance

- Workflow: project or assurance, with selection reason and existing policy.
- Requirements, affected behaviours, failure cases and predeclared acceptance rules.
- Capability dispositions: account for all 43 IDs once; link an existing inventory.
- Change impact: paths/inputs, requirement/check mapping, review and unresolved gaps.
- Scientific claim, units, independent reference, justified bounds and domain limits.

## Saved commands and evidence

| Required check / claim | Command, cwd and environment | Observed result and exit | Raw evidence |
| --- | --- | --- | --- |

- Candidate identity before and after: source, tests, config, relevant data and untracked inputs.
- Expected/actual exact test IDs, per-test outcomes and actual import/build origin.
- Static tool scope: configuration, exclusions, suppressions and unchecked type regions.
- Review: actual invocation, candidate reviewed, context/oracle separation and findings.
- Defect sensitivity: healthy/defective controls, assertion failures and raw logs.
- For paired audits: exact historical regressions, executable audit command, round/
  candidate identity, coordinator outcome and actual independent host invocation.
- Preserved failures, incomplete checks, timeouts and inaccessible artifacts.

## Completion

- Project checks passed, failed or incomplete; explain required gaps and optional limits.
- Final candidate/evidence comparison and review resolution.
- Saved rerun command and instructions for ordinary, scientific, plan-based and direct changes.
- HTML summary location and observed content/link/offline/no-JavaScript checks.
- Separate project results from tooling qualification and empirical validity.
- For assurance workflow only: full contract artifacts and deterministic gate outcome.
